Gemini keys

One key per line, exactly like the notebook: AIza…, LABEL=AIza… or AIza…,project. Keys are write-only — saving replaces the whole set.

Models

Every Gemini model the pool can use. Only the models listed here join the pool, and each one keeps its own Google limits — one model on one key is one quota bucket. Editing RPM, TPM or RPD changes how much the pool believes it may spend.

Task chains

Which models each task may use. The pool hands work to whichever listed model has the most room this minute, so select every model a task may spend. Models marked not in pool are ignored until they are added above.

Extraction

Scan crawled chapters for recurring names, sects, techniques and items. The local scan is free — jieba segments Chinese and the rules drop phrases and noise. The paid mode sends those candidates with the sentences they appear in, so one call keeps or drops each term and gives its category and English rendering. Frequency is added to existing terms; decisions and locked entries are never touched.

Glossary

Decide batch above settles every open term in one paid call: whether it is a term, its category and its English rendering. A decision already recorded is never asked about again, and editor-locked entries are never overwritten.

Translation style

The novel's source language and how its names should read. The language picks the extraction profile; the honorific policy steers the paid prompts, and the enabled categories limit what a model may choose. Leave every category selected to allow all of them.

Chapter translation

Pick a pass, select chapters, then queue them — or queue the whole novel in one job. Only chapters with crawled source text are translated. Web and Web+ are keyless; AI spends the key pool.

Translation jobs

Batches and their chapters, newest first. A job pauses when the pool is spent and resumes after the daily reset.

Application settings

Every config property this server exposes. Sensitive values (keys, passwords) are masked here and written from the section that owns them.
